검토 원칙

승인 전까지 공개 행사 목록에는 노출하지 않습니다.

  • 공식 URL이 없는 행사는 게시하지 않음
  • 추출값은 후보이며 관리자가 최종 확인
  • pending 상태에서만 추출 필드 수정 가능
  • 승인 시 published Event 생성

API 연결 메모

  • GET /api/event-drafts/
  • POST /api/event-drafts/
  • PATCH /api/event-drafts/{id}/
  • POST approve/reject actions

이 페이지는 목업입니다. 권한, CSRF, 오류 처리는 API 연결 단계에서 다룹니다.
