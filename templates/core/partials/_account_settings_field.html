{% comment %} _account_settings_field.html — label(+*) + input + field error, wired for IC4 (id="{id}-error", aria-describedby only when this field has an error). Renders the manually instead of `{{ field }}` — the only way to attach a conditional aria-describedby without a Python-side widget change (_auth_field.html's own version of this gap was deliberately deferred elsewhere, out of scope: 5 templates / 10 include sites outside this plan — see .docs/FE/auth-editorial.md M4 for the 「12개」 unit correction). Preserves any attrs the form field's widget already sets (autocomplete, maxlength, ...) by echoing widget.attrs verbatim. Password inputs never echo back `field.value` — Django's own PasswordInput renders empty for the same reason (render_value=False); reproducing that manually here matters because this partial replaces `{{ field }}` entirely. Usage: {% include "core/partials/_account_settings_field.html" with field=form.email label="이메일" %} {% endcomment %}
