{% comment %} 이벤트 달력(향후 활동 달력도 같은 계약을 쓸 예정) 공용 월 그리드다. 없이 요일 머리글과 날짜 셀을 같은 CSS grid의 형제로 둔다. 스타일: static/css/components/calendar.css. 사용법: {% include "core/partials/_calendar_grid.html" with weeks=weeks extra_query=extra_query %} weeks — 7일씩 담은 주 목록. 각 날짜는 {date, in_month, today, selected, items, more_count, count} 딕셔너리(date가 없으면 범위 밖 빈 칸, 링크 없이 렌더). items — 최대 2개의 {title, url, category_slug} — 셀 전체가 이미 하나의 링크라 url은 여기서 쓰지 않는다( 중첩 금지). more_count — 처음 2개를 넘는 나머지 이벤트 수("외 N개"). count — 그날 전체 이벤트 수(모바일 점/숫자용). extra_query — 활성 q/region/category/status 필터를 담은 쿼리스트링 꼬리. 요일 머리글과 날짜 셀을 하나가 아니라 두 개의 형제 .month-grid 컨테이너로 나눈 이유는, 에디토리얼 스킨이 날짜 셀만 감싸는 헤어라인 박스를 그리기 때문이다 — 두 컨테이너 모두 같은 .month-grid 클래스를 유지해 7열 CSS 그리드와 토/일 강조 색이 그대로 적용된다. {% endcomment %}
