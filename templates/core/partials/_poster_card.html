{% comment %} _poster_card.html — ticket-stub poster card (image tile + caption strip) Renders one event as a portrait poster tile. Image (poster or category emoji fallback) sits in `.poster-card-media`; the title + combined location/period line sit below it in an opaque `.poster-card-caption` strip, separated by a dashed perforation with punch-notch circles (ticket-stub signature #1 — prompt_plan.md §0 / PR-R2's `.tk-strip` technique). This replaces the old white-on-scrim caption overlay, which did not guarantee contrast on bright posters. `.poster-card-media` is a deliberate, minimal markup addition (the one markup change PR-R3's contract allows for the poster card): it gives the punch-notch pseudo-elements a box whose own bottom edge IS the seam (`top: 100%` on the notch, regardless of the image's actual rendered height), and — just as importantly — keeps `.poster-card-caption` free of `position: relative`, so the title's stretched-link (`.poster-card-title a::after`) still resolves against the outer `.poster-card` (its nearest positioned ancestor) and keeps the WHOLE card clickable, not just the caption strip. Badges / 찜 button keep their existing position:absolute rule (top/right 8px) — now anchored to `.poster-card-media` instead of `.poster-card`, which is the same pixel position (media sits flush at the card's top edge) so their placement is unchanged. The title is the ONLY link, stretched over the whole card via CSS (::after), so the entire poster is clickable. The 찜 (interest) button on closing cards sits above that stretched link with its own z-index, staying an independent control.
