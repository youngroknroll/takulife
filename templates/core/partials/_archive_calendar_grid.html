{% comment %} 활동 달력(calendar.html) 전용 월 그리드다. 이벤트 달력의 _calendar_grid.html과 셀 구조가 달라 분기 대신 별도 파셜로 둔다. 요일 머리글과 날짜 본문을 서로 다른 .month-grid 컨테이너로 나눈 이유도 _calendar_grid.html과 같다 — 헤어라인 박스가 날짜 셀만 감싸고 요일 라벨은 그 밖에 있어야 해서다. 사용법: {% include "core/partials/_archive_calendar_grid.html" with weeks=weeks extra_query=extra_query %} weeks — 7일씩 담은 주 목록. 각 날짜는 {date, in_month, today, selected, count, kinds, items, more_count} 딕셔너리(date가 없으면 범위 밖 빈 칸, 링크 없이 렌더). items — 해당 날짜 활동 최대 2건을 {group, label}로. 셀 전체가 이미 하나의 라 중첩을 피하려고 으로만 렌더한다. extra_query — 활성 type= 필터를 유지하는 쿼리스트링 꼬리. aria-label은 날짜의 활동 건수를 이미 포함하고 있고, aria-label이 하위 트리의 접근 가능한 이름 계산을 덮어써서 아래 항목 제목 들이 이름에 끼어들지 않는다. {% endcomment %}
