비활성 API 안내

이 페이지는 연결 준비용 목업입니다.

`/api/visit-records/`와 `/api/visit-record-photos/`는 현재 404가 정상입니다. 실제 연결 전에 archive 도메인에서 visit record와 photo API를 먼저 활성화해야 합니다.

미래 기록 규칙

  • 방문 기록은 로그인 사용자 소유 데이터
  • 공개된 행사에 대해서만 기록 생성
  • 사진은 JPEG, PNG, WebP만 허용 예정
  • 다른 사용자의 기록은 404로 숨김
