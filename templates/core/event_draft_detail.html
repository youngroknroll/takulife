드래프트 검토

드래프트 #{{ draft_id }}의 원문과 추출 후보를 비교하는 관리자 목업입니다. 실제 연결 시 pending 드래프트만 수정, 승인, 반려할 수 있습니다.

review_status: pending

추출 후보 편집

목업 폼입니다. 실제 PATCH에서는 `source_url`, `raw_title`, `raw_text`, `review_status`를 수정하지 않습니다.

원문 정보

raw 필드는 검토 중에도 원본 보존 대상입니다.

source_url

https://official.example/events/blue-archive-popup

raw_title

블루 아카이브 3주년 팝업스토어 공식 안내

raw_text

행사 기간, 장소, 특전, 예약 관련 안내가 포함된 공식 공지 본문 목업입니다.

검토 액션

실제 연결 시 CSRF와 admin 권한 처리가 필요합니다.

승인 결과는 draft object와 `event_id`를 함께 받는 API 응답으로 연결합니다.

필드 규칙

  • pending 상태에서만 extracted_* 필드 수정
  • source_url, raw_title, raw_text는 불변
  • 승인 후 공개 Event 생성
  • 반려한 드래프트는 공개 페이지에 노출하지 않음
