# 행사 타이포그래피 에디토리얼

## Current fact

공개 행사 경험은 포스터를 전제로 구성돼 있다. `Event.poster_image`가 공개 목록,
홈, 행사 상세, 스태프 품질 경고와 업로드 API에 연결돼 있으며, 이미지가 없을
때는 이니셜 타일·그라디언트·워터마크로 빈자리를 채운다.

행사 발견은 takulife의 최종 목적지가 아니라 방문 기록과 컬렉션 기여로 이어지는
진입점이다. 따라서 포스터의 시각적 풍부함보다 공식 정보의 신뢰도와 제목·날짜를
빠르게 비교하는 능력이 우선한다.

## Decision

2026-08-14 사용자 승인으로 서비스 전체의 공식 포스터 운영을 끝낸다.

- 공개 목록, 달력, 홈, 행사 상세, 활동 화면과 스태프 화면에서 포스터 및
  포스터 대체 장식을 사용하지 않는다.
- `Event.poster_image`, 포스터 업로드·교체·삭제 API와 관련 운영 지표를 제거한다.
- 저장된 포스터는 목데이터이므로 백업하지 않고 영구 삭제한다.
- 행사 정보의 시각적 중심은 작품명·행사명이고 날짜를 같은 시선 흐름에서 두 번째
  축으로 강조한다.
- Eventernote의 정보 중심 접근을 참고하되 화면을 복제하지 않는다. takulife는
  여백, 제목 위계, 날짜 열과 얇은 규칙선을 사용하는 에디토리얼 인덱스를 쓴다.

## Experience specification

### 행사 목록

기본 행은 왼쪽 날짜 열과 오른쪽 정보 열로 구성한다. 작품명은 짧은 표제,
행사명은 가장 큰 제목, 장소·전체 기간·카테고리·상태는 보조 정보로 둔다.
카드 테두리와 그림자 대신 여백과 규칙선으로 행을 구분한다. 카테고리 색은 작은
표식이나 짧은 선에만 쓰고 넓은 색면과 그라디언트는 쓰지 않는다.

모바일에서는 날짜를 제목 위 한 줄로 옮기고 세로 목록을 유지한다. 긴 한글·일본어·
영문 제목은 말줄임표 없이 줄바꿈한다. 날짜나 장소가 없으면 각각 `일정 미정`,
`장소 미정`을 표시해 누락을 장식으로 숨기지 않는다.

### 서비스 전체

- 홈의 포스터 덱과 행사 포스터 레일을 큰 제목·날짜 표제와 세로 텍스트 목록으로
  교체한다.
- 달력 칸에는 짧은 행사명과 상태 표식만 두고, 선택 결과는 같은 에디토리얼 행
  체계로 연결한다.
- 행사 상세는 포스터 열을 없앤 단일 콘텐츠 칼럼으로 구성한다. 작품명, 행사명,
  날짜, 장소, 운영 시간, 공식 출처, 상태와 사용자 행동을 문서 표제처럼 배치한다.
- 관련 행사와 활동 화면의 예정 행사는 날짜·제목·장소를 갖춘 축약형 텍스트 행을
  사용한다.
- 스태프 검수는 공식 URL, 출처명, 기간, 장소, 작품명과 재검증 상태에 집중한다.
- 행사별 공유 이미지를 만들지 않고 서비스 공통 브랜드 이미지만 사용한다.

### Interaction and accessibility criteria

- 날짜는 의미 있는 `time` 요소로, 작품명과 행사명은 올바른 제목 계층으로
  구성한다.
- 상태는 색뿐 아니라 `진행 중`, `오픈 예정`, `종료 임박`, `종료` 텍스트로
  전달한다.
- 행의 탐색 링크와 찜 버튼의 클릭·포커스 영역은 겹치지 않는다.
- 필터, 정렬, 목록·달력 전환, 찜의 키보드 조작과 기존 실패 복구를 유지한다.
- 찜 요청 중 중복 입력을 막고 실패 메시지를 해당 행사 행 안에서 알린다.
- 모바일에 행사 가로 스크롤 목록을 새로 만들지 않는다.
- 라이트·다크 테마에서 긴 제목, 누락 정보, 빈 결과와 상태색을 확인한다.

## Guardrail

- 행사 수집·게시 경로는 이미지 URL이나 이미지 파일을 받거나 외부에서 가져오지
  않는다.
- 포스터가 없음을 표현하는 이니셜 타일, 그라디언트, 워터마크도 만들지 않는다.
- 이미지 제거를 이유로 날짜·장소·공식 출처의 정보 품질 기준을 낮추지 않는다.
- 이미지 파일 영구 삭제는 승인된 목데이터에만 적용한다. 이후 컬렉션·방문 기록의
  사용자 사진 보존 정책으로 일반화하지 않는다.
- 동적 공유 이미지 생성, 새 폰트 의존성, 행사 추천 로직 변경과 정보 모델 확장은
  이번 범위 밖이다.
- 삭제된 목이미지 2,869개(14M) `[실측 2026-08-15]`는 백업이 없어 복구할 수 없다.
  포스터 없음을 메우려는 어떤 대체 장식(이니셜 타일·그라디언트·워터마크 등)도
  재도입하지 않는다.
- `Event.poster_image`를 되살리는 결정은 이 문서가 아니라 새 제품·저작권·운영
  승인과 별도 마이그레이션을 요구한다. 이번 삭제를 근거로 조용히 되돌리지 않는다.

## Domain boundary and dependency direction

`events`는 공개 행사 데이터와 포스터 필드·API 제거를 소유한다. `web`은 그
데이터를 포스터 없이 표현하고, `archive`는 기존 사용자 찜·방문·컬렉션 상태를
계속 소유한다. 승인된 `archive -> events` 의존 방향은 바뀌지 않는다.

포스터 제거는 새 교차 도메인 서비스나 저장소 추상화를 만들지 않는다. 기존
이미지 저장 기반은 컬렉션과 방문 사진 때문에 유지하며, 행사 전용 참조만 없앤다.

## Verification contract

- 백엔드 필드·API·품질 집계 제거는 승인된 Test List에서 한 시나리오씩
  Red-Green-Refactor로 진행한다.
- 프론트엔드 표현은 자동화 테스트를 추가하지 않고 실제 Chromium으로
  320px·768px·1440px 뷰포트에서 검증한다.
- 브라우저 검증은 긴 제목, 누락 날짜·장소, 빈 결과, 필터 적용, 찜 성공·실패,
  키보드 이동, 콘솔 오류와 가로 오버플로를 포함한다.
- 전체 백엔드 회귀, Django 검사와 마이그레이션 드리프트 검사를 새로 실행한다.
